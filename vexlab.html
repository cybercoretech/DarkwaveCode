02 / FROM SOURCE TO SIGNAL
READ IT.

The Vex CLI separates interpreting a program from validating and inspecting its lowered form. Each command reports its actual boundary clearly.
READ THE LANGUAGE GUIDE ↗
INTERPRETcargo run -- run program.vex
TYPE CHECKcargo run -- check program.vex
INSPECT TYPED IRcargo run -- build program.vex
EXPERIMENTAL QBE ILcargo run -- qbe program.vex
QBE currently supports only the verified scalar target subset and emits intermediate IL; it does not build a native executable.
